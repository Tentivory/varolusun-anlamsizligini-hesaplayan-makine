## Resmi Bilimsel Açıklama

Bu proje, insanlığın en büyük sorusuna **kesin** cevap vermek için tasarlanmıştır:  
**Her şey ne kadar anlamsız?**

Yıllarca süren araştırmalar, binlerce satır kod ve bir fincan soğuk çay sonucunda ortaya çıkan bu makine, varoluşun anlamsızlığını **yüzde 99.999** hassasiyetle hesaplar.  
(Kalan %0.001'lik kısım, hâlâ 'belki bir gün' diyenlerin umudundan kaynaklanır.)

## Nasıl Çalışır?

1. Terminalini aç.
2. `python hesapla.py` yaz.
3. Ekranda akan muhteşem bilimsel süreçleri izle.
4. Sonuçla yüzleş.
5. Hayatına devam et (çünkü başka seçeneğin yok).

## Kurulum

```bash
git clone https://github.com/Tentivory/varolusun-anlamsizligini-hesaplayan-makine.git
cd varolusun-anlamsizligini-hesaplayan-makine
python hesapla.py
```

Python 3.x yeterlidir. Başka bir şeye ihtiyacın yok. Hatta Python'un kendisine bile ihtiyacın yok aslında, ama olsun.
